CarLeague

A fast-paced multiplayer vehicle soccer game inspired by Rocket League, built with Unity and Photon Fusion.

Features
Real-time multiplayer using Photon Fusion
Vehicle movement and physics
Goal scoring system
Match timer
Networked player synchronization
Third-person camera system
Simple arena gameplay
Tech Stack
Unity
C#
Photon Fusion
Gameplay

Players control cars and try to push the ball into the opponent's goal. The team with the most goals wins the match.
